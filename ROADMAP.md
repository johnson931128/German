# Roadmap

This roadmap describes possible learning stages. It is not a commitment to implement every item.

## Phase 0 — Project Foundation

- Rust project structure
- CLI
- Basic protocol and data model

## Phase 1 — Single Broker

- Record
- Topic
- Partition
- Append-only log
- Producer
- Consumer
- Offset

## Phase 2 — Multi Broker

- Broker identity
- Broker communication
- Partition assignment
- Heartbeat
- Failure detection

## Phase 3 — Replication

- Leader/follower
- Log replication
- Acknowledgement semantics
- Recovery

## Phase 4 — Coordination

- Leader election
- Metadata coordination
- Consistency experiments

## Phase 5 — Advanced Experiments

- Checkpoint and recovery
- Stream processing
- Performance experiments
- Compare implementation decisions with Apache Kafka
